Bước 1: Mở Codex trên Windows.

Bước 2: Nhập yêu cầu sau, thay YOUR_ORG bằng tên GitHub của bạn:

```
$skill-installer install https://github.com/YOUR_ORG/ai-agent-skills/tree/main/skills/business-investigator
```

Codex sẽ sử dụng Skill Installer để lấy thư mục business-investigator từ repository và cài vào thư mục skill của nó.

Bước 3: Mở lại Codex, sau đó kiểm tra:

```
$business-investigator
```

Điều tra nghiệp vụ PaymentService.approvePayment.
